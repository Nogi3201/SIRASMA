# Project Overview — SIRASMA

## Deskripsi

**SIRASMA** (Sistem Informasi Reservasi Asrama ULBI) adalah aplikasi web full-stack untuk manajemen dan reservasi kamar asrama Universitas Logistik dan Bisnis Internasional (ULBI).

Sistem ini menyederhanakan proses pendaftaran, pemilihan kamar, dan administrasi asrama yang sebelumnya dilakukan secara manual atau melalui sistem yang terpisah.

---

## Tujuan Sistem

- Menyediakan platform terpadu untuk reservasi kamar asrama.
- Memudahkan mahasiswa dalam memilih dan mendaftar kamar.
- Membantu admin/staff mengelola data penghuni, kamar, dan pembayaran.
- Menyediakan laporan dan data yang mudah diakses.

---

## Ruang Lingkup

| Fitur | Keterangan |
|---|---|
| Autentikasi | Login, registrasi, manajemen sesi |
| Manajemen Kamar | CRUD kamar, tipe kamar, lantai, gedung |
| Reservasi | Pengajuan, persetujuan, penolakan |
| Penghuni | Data mahasiswa penghuni, riwayat |
| Pembayaran | Tagihan, konfirmasi pembayaran |
| Laporan | Rekap hunian, pendapatan |

> Detail fitur dan prioritas akan didefinisikan di dokumen Task berikutnya.
